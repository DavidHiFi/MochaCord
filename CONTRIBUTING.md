# Contributing

Thanks for helping MochaCord. It is a CSS theme, so most contributions are tweaks and screenshots.

## Ways to help

- Report broken selectors after Discord, Vencord or Equicord updates
- Send theme fixes as small CSS changes
- Share screenshots of anything that looks off

## Getting set up

No build step. Edit the CSS and reload the client to see your change.

## Checks before a pull request

- Screenshot before and after your change
- Check the change in a plain client and with the plugins you use

## Where to submit

Open issues and pull requests in this repository.
